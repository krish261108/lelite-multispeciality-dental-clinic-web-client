# L’ELITE media pack

Place approved clinic photography/video in this directory when the final media pack is available.

Suggested files:
- `hero.mp4` — optional scroll-scrub hero sequence
- `clinic.jpg` — clinic interior/exterior
- `doctor.jpg` — approved clinician portrait
- `smile.jpg` — approved smile/orthodontic imagery

The current site intentionally uses an original CSS dental visual instead of inventing or hotlinking third-party clinical photography. This keeps the experience deployable while protecting image licensing and authenticity.
