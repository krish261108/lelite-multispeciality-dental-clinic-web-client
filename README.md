# L’ELITE Multispeciality Digital Dental Care

A production-ready Next.js landing site for L’ELITE Multispeciality Digital Dental Care, Puducherry.

## Stack
- Next.js App Router + TypeScript
- Tailwind CSS v4
- Motion for React (Framer Motion successor package)
- Lucide React icons

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Import this repository into Vercel. No custom server is required.
